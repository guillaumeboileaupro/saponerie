# Logos de La Saponnerie

Trois variantes SVG validées sont conservées :

- `la-saponnerie-detailed.svg` : logo complet avec le nom, adapté au README et aux écrans de présentation ;
- `la-saponnerie-glow.svg` : variante lumineuse expérimentale ;
- `la-saponnerie-minimal.svg` : pictogramme principal recommandé pour l’icône de l’application.

Les fichiers sont vectoriels, modifiables et utilisent principalement le bleu `#174A70`. Leur fond est transparent.

Avant la génération des paquets Tauri, produire les tailles PNG et les formats d’icône Windows/Linux à partir du pictogramme minimal, sans modifier le SVG source.
