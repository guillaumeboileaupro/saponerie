# Décisions d’architecture

Les décisions structurantes sont consignées ici sous forme d’ADR.

Format de fichier : `NNNN-titre-court.md`.

Chaque ADR contient :

- contexte ;
- options étudiées ;
- décision ;
- conséquences ;
- date et statut.

Premiers ADR prévus :

1. pile Tauri 2 + React + TypeScript ;
2. langage et représentation décimale du moteur ;
3. format et provenance du jeu de données SAP ;
4. stockage local et migrations ;
5. formats d’installation Windows et Ubuntu.
