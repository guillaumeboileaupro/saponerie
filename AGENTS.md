# Instructions du projet La Saponnerie

Le produit est un calculateur de recettes de savon distribué comme application de bureau Ubuntu et Windows.

- Utiliser Tauri 2, React et TypeScript sauf décision documentée contraire.
- Séparer strictement moteur de calcul, données SAP, interface et stockage.
- Toute formule ou table SAP doit avoir une source et des tests.
- Ne pas présenter un résultat comme une garantie de sécurité.
- Ne pas pousser, fusionner ou publier une release sans demande explicite.
- Conserver une couverture élevée sur le moteur métier et tester les cas limites.
- Utiliser les skills du dépôt lorsqu’ils correspondent à la tâche.
